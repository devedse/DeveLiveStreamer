# DeveLiveStreamer

A mobile app for live streaming, with camera and screen sharing, OBS-style scenes and sources, and configurable low-latency output.

The Android app composes OBS-style scenes on the GPU and streams them over **SRT** (for DeveStreamingPlatform / OvenMediaEngine) or **RTMP/RTMPS**. It is built with C# and .NET MAUI; the scene model and editor are shared with a future iOS build.

## Features

- Scenes with layered sources: cameras (pick any lens), the device screen, incoming RTMP/SRT streams (pulled, or pushed to the phone), images, text and colors.
- Drag, resize, order, hide and lock sources; precise transforms in Properties; undo/redo; automatic saving with backup recovery; JSON import/export.
- The preview is the compositor's actual output frame.
- **Go live** with H.264 or HEVC hardware encoding and AAC audio (microphone, device audio and network-source audio mixed). Custom resolution and rational frame rate with no app-imposed limits; CBR/VBR, keyframe interval, profile and B-frames.
- SRT latency down to 0 ms, stream IDs and passphrases; automatic reconnects; live bitrate, FPS, RTT and dropped-frame statistics; keeps streaming in the background.

See the [user guide](docs/editor-guide.md).

## Build an APK

Linux x86-64 bootstrap (downloads .NET, MAUI Android, JDK and SDK tools; accepts the Android SDK licenses):

```bash
./eng/setup-android.sh
./eng/build-android.sh
```

Use an explicit tool directory when needed, for example `./eng/setup-android.sh /tmp/deve-live-streamer-tools`. For an existing environment, set `DOTNET_ROOT`, `JAVA_HOME` and `ANDROID_HOME`; the build script also reads the ignored `.tools/env.sh` generated by setup.

The script runs the tests (including SRT/RTMP interoperability with FFmpeg when it is installed) and creates a Release-configuration, development-signed APK for **Android 10+**, containing ARM64 and x86-64 native runtimes, under `artifacts/android/`. It verifies the package signature, signing identity, ABI coverage, ZIP alignment and SHA-256 checksum. The local development keystore is reused from `.tools/` for subsequent updates.

GitHub Actions produces downloadable APK artifacts for pushes and pull requests. Configuring the four Android signing secrets enables release signing and publication on successful master pushes. See [development and build notes](docs/development.md) for commands, architecture, signing and validation details.

The local [research index](research/README.md) contains source checkouts, app comparisons, platform compatibility findings, build analysis and the proposed project setup. The entire `research/` directory is intentionally gitignored and is not included in a normal clone.

The original [logo and generation notes](docs/branding/README.md) are tracked project assets.
